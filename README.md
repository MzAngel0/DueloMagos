# Duelo de Magos 🧙‍♂️

Videojuego de consola por turnos desarrollado en Java como proyecto final 
de Lógica y Programación — ITM.

## Descripción
Dos magos de distintos tipos se enfrentan en combate por turnos. 
Cada mago tiene vida, maná y un hechizo especial único.

## Tipos de Magos
- **MagoFuego**: daño alto garantizado
- **MagoHielo**: puede congelar al rival y hacerle perder un turno
- **MagoRayo**: puede fallar o hacer golpe crítico doble

## Conceptos POO aplicados
- Herencia con `extends` y `super()`
- Encapsulación con getters/setters
- Polimorfismo con `@Override`
- Array de tipo padre con for-each

## Tecnologías
- Java JDK 22
- IntelliJ IDEA
